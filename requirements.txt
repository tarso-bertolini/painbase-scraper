# Production deps for the Scrapling-based scraping fleet.
# Python 3.11+ recommended (Scrapling needs >=3.10).

# Anti-bot scraping framework. BSD-3-Clause.
# https://github.com/D4Vinci/Scrapling
# Bundled features we rely on:
#   - StealthyFetcher (Camoufox-based, defeats Cloudflare Turnstile)
#   - TLS fingerprint impersonation (Chrome/Firefox/Safari)
#   - Adaptive selectors that survive HTML changes
#   - Built-in proxy rotation
#
# `[fetchers]` extra pulls Playwright + curl_cffi (needed for
# StealthyFetcher.fetch). Without the extra Scrapling installs as a
# parser-only library and `from scrapling.fetchers import …` raises.
scrapling[fetchers]>=0.4.7

# Stealth-tuned Firefox build, driven by Scrapling's StealthyFetcher.
# Pulled separately so that the workflow's `python -m camoufox fetch`
# step actually finds the module to invoke.
camoufox>=0.4.11

# HTTP client used by the ingest module to POST scraped batches back
# to the Painbase API. Pinned conservatively — anything 2.x works.
httpx>=0.27.0
